# pc-tools

Non-secret scripts backed up from the PC (`PC-Workspace`). Never commit `cookies.txt`, `*.token`, `muse_sdk_token*`, `.debug-key`.

- `agent-desktop/` Muse connector for PC desktop control (:8001 via supergateway)
- `windows-mcp/` Windows-MCP launcher (set up, unused)
- `echo-muse/` Echo Dot / Google TV Home Link setup (blocked on USB pairing)
- `ipad-debug/` iPad remote debug proxy and screenshot tools
- `tv-assistant/` fake TV bridge (Python). The Jarvis TV app APK is not included.
